# 都说 Apple TV 那只遥控器值两百，我让小米 2 Pro 强兼了索尼

## 背景

最近 CleanYourTV 很火，能把 Android TV 直接刷成苹果风味的桌面。

但 Apple TV 值钱的从来不只是系统。硬件也是一大亮点——那只遥控器摸过的人都知道，铝合金、无刻度、拇指一放就知道在哪，网上那句"Apple TV 的遥控器就值两百"不是玩笑。

我找了一圈 Android TV 体系，最接近它的只有一只：**小米蓝牙遥控器 2 Pro**。窄、轻、蓝牙、带语音，按键少到不会误触。

问题是它有两个"官方不通"：

1. 小米蓝牙遥控器 2 Pro 是小米生态的设备，官方只保证小米电视能用；
2. 我家是索尼，而且我一度坚信索尼把蓝牙白名单焊死了——系统「添加设备」那个列表，扫了两分钟，一个设备都没有。

所以这件事的原始设定是：让小米强兼索尼。

## 结论

**完美适配，方向、确认、返回、主页、音量、菜单、开关、TV（改成切换输入）统统正常，重启自动重连。**

不刷机、不 root、不拆机、不换电视也不换遥控器。全套动作就是：**在电视上开一次 ADB，然后把一段提示词交给一个能跑命令的 AI。**

两堵墙我都撞过，都不是墙：

| 我以为的问题 | 真实情况 |
|---|---|
| 小米遥控器只认小米电视 | 它走的是标准 BLE HID（HOGP），任何蓝牙 HID 主机都能收。真被绑死的只有语音键和几个专属键 |
| 索尼锁了蓝牙白名单 | 锁住的不是协议栈，是**设置里那个"添加设备"界面**——它按设备类型过滤，第三方遥控器不显示。协议栈全程在正常扫描 |

所以"不兼容"和"白名单"这两句话都是真的，但结论不该是妥协。

## 用法

照 CleanYourTV 的路子，你只负责两件事，剩下的交给 AI。

### 第 0 步：开 ADB（唯一必须你亲手做的）

AI 替不了这一步，因为此时它还没连上你的电视。

索尼 BRAVIA（Android 9 / Google TV）：

1. `设置 → 系统 → 关于`
2. 光标停在「版本」上，连按 OK **7 次**（部分新固件改成在「Android TV OS build」上按 10 次），出现「您已是开发者」
3. 回 `设置 → 系统 → 开发者选项`，打开 **USB 调试**；有「网络调试」也一起开
4. 电视保持开机，别让它待机——有些固件从待机醒来会把调试开关关掉

菜单名各代固件不一样，找不到就搜「型号 + 开启 ADB」，但"连点版本号"这套逻辑是通的。

### 第 1 步：把提示词喂给能真正执行命令的 AI

关键：**要能跑 shell 的**。网页版聊天框只能把命令念给你听，它连不上你家电视。

新建一个任务，把下面这段整段贴进去，方括号填好。它会自己装工具、扫描、配对、修键；需要你在电视上动手时会停下来提醒你。

```text
请在我家的索尼 Android TV 上完成一件事：接入一只「小米蓝牙遥控器 2 Pro」，
并修好它按了没反应的 Home 键和 TV 键。你没有 root，也不需要 root，
全部操作走局域网 ADB。

【设备信息】
电视：索尼 BRAVIA，Android 9（SDK 28）
电视 IP：[填你的电视局域网 IP]
电脑：macOS
遥控器：小米蓝牙遥控器 2 Pro，广播名一般含「小米蓝牙遥控器」，
按名称关键字模糊匹配即可，不需要 MAC 地址。

【阶段一 · 接通 ADB】
1. 我已在电视上打开「USB 调试」，连接后电视会弹「允许 USB 调试吗」，我来确认。
2. 先 adb connect <IP>:5555，等 devices 状态变成 device 再继续。授权有延迟，
   最多等 60 秒，不要连续重连把弹窗刷掉。
3. 读回机型、Android 版本、SDK 版本，确认是 Android TV 且 ≥ Android 8。
   不满足就停下说原因，不要硬做。

【阶段二 · 配对遥控器】
1. 先查 dumpsys bluetooth_manager 的 Bonded devices，看是否已配对过。
2. 不要依赖系统的「添加设备」界面：它按设备类型过滤，第三方遥控器经常列表为空，
   会误导你以为设备没在广播。
3. 直连配对要用应用层 createBond：写一个最小 APK（扫描 + 按名称匹配 + 配对），
   编译用 Android SDK build-tools + javac + d8，不要装 Gradle。
4. 全程不需要 MAC，也不要让我念 MAC 或从列表里挑一台，按设备名关键字匹配即可。
5. 顺序很重要：先把工具装好、无障碍服务启用、一切准备就绪，**再**让我长按
   遥控器【主页键 + 菜单键】5 秒进配对模式。别在我按完之后还在编译。
6. 扫描要循环（如 20 秒一轮、最多 8 轮），扫到即配对。我切配对模式可能比扫描
   慢半拍，只扫一轮就报"找不到"会白折腾。配对失败的要自动跳过换下一台。
7. 若日志出现 result: 0x05 并伴随 pairingVariant 0 passkey，说明对方要 6 位密码
   而设备没有数字键盘，这类配不上，直接说换设备，不要反复重试。

【阶段三 · 打通 HID 通道】
1. 配对成功不等于能用。检查 HidHostService 的 mInputDevices 是否为空。
2. 为空不是厂商封锁，是 Android 9 把 BluetoothHidHost.connect() 和 setPriority()
   放进了隐藏 API 黑名单，普通反射会抛 NoSuchMethodException。
   不要因此判断"方法不存在"。
3. 解法：双重反射调用 VMRuntime.setHiddenApiExemptions("L") 解除限制，
   再 setPriority(dev, 100)，然后 connect(dev)。状态应为 0 → 1 → 2。
4. 三项验收缺一不可：mInputDevices 显示 : 2；dumpsys input 里出现
   /dev/input/eventN；getevent -lt 该节点按方向键能看到 MSC_SCAN 0007004f / KEY_RIGHT。

【阶段四 · 修 Home / TV 键】
1. 先解释再动手：这只遥控器的 Home 发的不是 KEYCODE_HOME(3)，是
   KEYCODE_MOVE_HOME(122)——文本框"移到行首"用的键，电视上没有文本框，所以没反应。
   TV 键发 KEYCODE_GRAVE(68)，也是个没人接的空键。
2. 不要改 /system/usr/keylayout（只读，无 root 改不了），
   也不要试图注入按键（INJECT_EVENTS 是签名权限）。
3. 正确路径：装一个无障碍服务做按键重映射。它只能做两件事——执行系统全局动作，
   或启动某个 Activity。别承诺它能"拦截 A 键发出 B 键"。
4. 映射写进 Settings.Secure，改完即时生效，不用重启：
   Home(122) → 系统主页
   TV(68)   → 输入选择
5. 索尼的输入选择是 com.sony.dtv.tvx/com.sony.dtv.tvx.inputselect.InputSelectionActivity，
   直接 startActivity 会在一秒内自退，必须附带 KEY_EVENT extra，键码用
   KEYCODE_TV_INPUT(178)，flag 用 NEW_TASK | CLEAR_WHEN_TASK_RESET | NO_ANIMATION。

【阶段五 · 验证】
1. 让我按 Home 和 TV 键实测。判断浮层是否弹出要看截图 + 方向键高亮是否移动，
   不要看 mCurrentFocus——这类浮层不抢焦点，那个字段仍显示桌面，会误判成失败。
2. 不要用 input keyevent 自测映射：注入事件带 FLAG_INJECTED，不经过无障碍
   按键过滤器，测了也是白测。必须真按遥控器。

【可选 · 语音键】（默认不做，我说要做再动）
1. 语音键和 TV 键同类：键码能抓到，缺的是接到系统语音入口。照 TV 键的方式做——
   先 getevent 抓真实键码，写进映射时动作用 s（ACTION_ASSIST），然后真按遥控器测。
2. 预期风险：电视本体没有麦克风（/proc/asound/cards 为空），映射后可能只弹一句提示就退出。
   如果界面能起但没声音输入，告诉我改走手机 Google TV App 走 WiFi 送语音。
3. 不要为语音键改 /system、改 audio_policy、装第三方语音助手或替换系统 launcher。

【约束】
1. 不要 adb root（量产机必然失败），不要改 /system，不要卸载系统应用。
2. 不要启动 factory / fac menu / production 等工厂测试包。
3. 全程把实际命令输出给我看，不要只说"已完成"。
4. 最后告诉我：装了什么、改了哪些系统设置、怎么一键回滚、ADB 怎么关。

需要我在电视上操作时，先停下来告诉我按什么、按几下。现在开始。
```

### 第 2 步：你只需配合三件事

1. **在电视上点「允许」**——弹窗出现时确认，勾上"始终允许"
2. **让遥控器进配对模式**——等 AI 说"准备就绪"之后，再同时长按「主页键 + 菜单键」5 秒至指示灯快闪。**先把手机蓝牙关掉**，遥控器连着手机就不再广播了
3. **逐键验收**——方向、确认、返回、主页、音量、菜单、开关、TV 各按一次。TV 键应该弹出「输入选择」浮层，而不是黑一下没动静

## 过程：它实际是怎么被跑通的

给想看原理的人。每一步都有实际输出，不是推测。

| 阶段 | 动作 | 看到什么 |
|---|---|---|
| 扫描 | 系统「添加设备」页开 2 分钟 | 界面始终空；蓝牙栈日志持续 `btif_get_device_type ... type 1`，还夹着 `discarding advertising packet`——UI 在丢包 |
| 配对 | `createBond()` 直连 | `BOND_NONE → BONDING → BONDED`，1.2 秒，设备名「小米蓝牙语音遥控器」，带 `[LE]` 标记 |
| 接通 | 接上 HID 通道 | `Connection state: 0->1->2`，`mInputDevices: <MAC> : 2` |
| 落地 | `dumpsys input` | 第 5 号设备 = 遥控器，`/dev/input/event4`，`vendor=0x2717`（小米），`Sources=0x101`（键盘 + D-pad） |
| 验真 | `getevent -lt` | `MSC_SCAN 0007004f → KEY_RIGHT`、`0x70050 → KEY_LEFT`，DOWN/UP 完整，标准 HID 键盘用法码 |
| 修键 | 无障碍过滤器 | `code=122 KEYCODE_MOVE_HOME` → `remap 122 -> global 2 ok=true`，按 Home 回桌面 |
| 修键 | TV → 输入选择 | `code=68 KEYCODE_GRAVE`，带 `KEY_EVENT(178)` 拉起后浮层常驻，方向键能把高亮从第一项移到第二项 |

两个值得记下来的判断纠正：

- `Settings.Global.bluetooth_input_device_priority_<MAC>` **不是**旧版遗留的废键，它就是 Android 9 存 HID 优先级的地方，`setPriority(100)` 写的就是它，重启不丢，之后遥控器回到范围内自动回连。
- 索尼**没有**在 HID 准入上做拦截。整个过程零 `Permission Denial`，配对记录一落盘就是标准输入设备。

## 未验证：语音键，理论上可行

这一项我停在"没验"，不是"验不通"。

老索尼的语音我自己懒得折腾，所以只做到初步探路。探到的两条事实是：这台电视本体**没有麦克风**（`/proc/asound/cards` 为空、`audio_policy` 里 input 设备为空、`pm list features` 只有 `android.hardware.audio.output`），而索尼的语音链路是"遥控器麦采集 → 蓝牙回传 → 电视识别"。也就是说，只把语音键映射成一个"唤起语音"的键，画面能起来，但电视没有拾音的地方。

但它跟 Home / TV 其实是同一类问题：**按键本身是通的，缺的只是把按键接到系统语音入口那一步。** 手上既然已经有一套能改键的无障碍服务，这条路是现成的——TV 键怎么处理，语音键就怎么处理。

（备注：语音键抓到的是 `KEYCODE_F5(135)`。）

万一画面起来了却没声音输入，还有条备用路：手机装 Google TV App 走 WiFi，用手机的麦把语音送进去，电视端这条通道是通的。

有兴趣的可以让 agent 顺着 TV 键的写法试一遍。改键不重启、不碰分区，试错了也不影响已经通的那些键。真想要"一按就说话"的稳定体验，还是原厂语音遥控器最省事。

## 值不值

CleanYourTV 把皮换了，这只遥控器把"手感"换了。

先说价格：**小米蓝牙遥控器 2 Pro 是 99 元，小米蓝牙遥控器 2 是 59 元**，闲鱼上全新能淘到 6 折左右——2 Pro 六十块上下就能拿到。Apple TV 那只遥控器单买两百多，而这里花 99（甚至 60）就买到了"值两百"的那部分手感。

之前是三个遥控器摊在茶几上——电视的、机顶盒的、音响的。现在一只，窄到拇指不用挪窝就能从方向键滑到音量，Home 和 TV 两个原本的死键被点活。

代价是拧了一次 ADB、装了两个几 KB 的小工具、改了两条系统设置。做完把调试口子一关，电视里没留着任何可疑的东西。

顺手补一句安全：ADB 的 5555 端口是明文传输，别长期敞开。全部做完就关。

## 回滚

```bash
# 停用按键映射（立刻恢复原始键位）
adb shell settings put secure enabled_accessibility_services ''

# 卸载工具（配对关系还在，遥控器照用，只是键位回原样）
adb shell pm uninstall <重映射工具包名>
```

然后电视上：`设置 → 开发者选项 → 撤销 USB 调试授权`。
